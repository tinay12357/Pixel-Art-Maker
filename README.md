#Pixel Art Maker
## Description
A program for making pixel art, whether it's for fun or your next pixel art stye game! <br><br>

### Features:
- Custom colors and palette
- Resizeable grid/canvas size
- Gridlines toggle
- Download to PC

NOTE: that to change colors you must click "Change color" after selecting the desired color.
No known severe bugs, however several drawings in the same session may result in canvases that overlap if not hidden. 
UI can be improved/moved to the top/bottom on in the future
